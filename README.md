# ASMW Score Assist

The show list runs from **2101 through 2130**. Each show remains an independent episode with its own teams, scores, logs, Edit Notes, progress, and Capitalization Round setup.

If older browser data used Show 1 through Show 30, the app automatically maps those records to Show 2101 through Show 2130 when first opened.

## GitHub Pages

Upload `index.html`, `.nojekyll`, and `README.md` to the repository root. Under **Settings > Pages**, deploy from the `main` branch and `/ (root)`.
